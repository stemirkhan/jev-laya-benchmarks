# Jev, Laya и специализированные реранкеры

Код эксперимента на SciFact, FiQA и NFCorpus. Сравниваются Jev 1.13 через OpenRouter, Laya Multilingual, BGE-reranker-v2-m3 и Qwen3-Reranker 0.6B/8B.

Для каждого запроса подготовлены два независимых списка кандидатов: BM25 top-20 и гибридный поиск BM25 + векторы + RRF top-20. Все модели получают одинаковые документы внутри каждого списка. Генерации ответов и LLM-судьи нет.

Основной тест: 1271 запрос, 2542 списка и 50 840 измеряемых пар на модель. Прогрев отдельно, в основных тестах ошибок и повторных попыток нет. Полные документы не обрезались. Настройки закреплены по отдельным train/dev-пилотам до оценки test.

Jev и Qwen3-Reranker-8B дали наиболее высокое среднее качество. Laya Multilingual снизила NDCG@10 на всех трех наборах в обоих вариантах поиска; это результат выбранной конфигурации, не вывод о всех моделях Laya. BGE был самым быстрым в замерах задержки и потока.

## Код и воспроизведение

Python 3.12+, `uv`. Команды подготовки скачивают публичные наборы, токенизаторы и веса. Платные API-вызовы не запускаются установкой или тестами.

```sh
uv sync --frozen --group dev
uv run pytest -q
```

[Пошаговые команды](docs/reproduction.md) описывают подготовку данных, кандидатов, новые пилоты, фиксацию протокола, GPU-тест, вызовы Jev и расчет метрик. Для нового запуска нужен собственный протокол, а не повторное использование журналов старой машины.

| Файл | Назначение |
|---|---|
| `prepare.py`, `audit.py` | Скачать наборы и проверить длину входов |
| `prepare_embedding.py`, `retrieval.py` | BM25, векторы и общие кандидаты |
| `prepare_inference.py`, `local_adapters.py` | Веса и адаптеры локальных моделей |
| `rerank.py`, `freeze_protocol.py` | Пилот, фиксация условий и основной тест |
| `openrouter_adapter.py`, `openrouter_run.py` | Jev через Decisions API OpenRouter |
| `jev_adapter.py` | Прямой API TypeSafe, использован только в отдельном пилоте |
| `evaluate_rerank.py` | NDCG@10, Recall, MRR, bootstrap и задержка |
| `throughput.py`, `retrieval_latency.py` | Отдельные замеры потока и первичного поиска |

В публичном пакете адаптер OpenRouter совпадает с использованным в эксперименте. Обертка `openrouter_run.py` подготовлена для повторного запуска: вместо старых ограничений по дате и учетной записи она требует явные лимиты бюджета, числа запросов и времени. Вычислительные адаптеры и результаты не менялись. В `prepare.py` закреплены исторические ревизии токенизаторов.

## Условия измерений

- Основной GPU-тест: одна NVIDIA GeForce RTX 5090 32 ГБ, модели последовательно. Подготовка поиска и векторов: Intel Core i7-12700H, CPU.
- Throughput: другая RTX 5090 32 ГБ; три прохода по 480 парам после прогрева, прежние размеры батчей.
- Laya: FP32 с TF32, batch 4. BGE: FP16, batch 4. Qwen 0.6B: BF16, batch 4. Qwen 8B: BF16, batch 2. Квантования нет.
- Jev: `typesafe/jev-1.13-20260917`, четыре параллельных HTTP-вызова внутри списка. Задержка включает сеть.
- Задержка списка не включает первичный поиск, загрузку весов и прогрев. Throughput не вычислялся как 20 / медиана и не является максимумом производительности GPU.
- NDCG считается по исходной разметке BEIR. Неразмеченный документ дает нулевой вклад, но не обязательно бесполезен.
- Bootstrap-интервалы сравнивают модель с исходным поиском, не модели между собой.

Основной тест Jev стоил $1,29735, вместе с OpenRouter-пилотом и прогревом - $1,312504116. Это исторические расходы эксперимента, не обещание текущей цены. API может изменить модель, тариф и условия доступа; обертка прекращает новый запуск при несовпадении закрепленных условий.

## Графики

Готовые PNG и SVG находятся в `graphics/final/`. Генератор трех графиков читает локальный снимок чисел, не вызывает модели:

```sh
npm install --no-save --package-lock=false sharp@0.35.4
node graphics/source/build-charts.mjs
```

Для совпадения шрифта нужен Noto Sans. Три схемы можно открыть в бесплатном [Excalidraw](https://excalidraw.com/) из `.excalidraw`-файлов.

## Что не включено

Здесь нет полных корпусов BEIR, весов моделей, ключей, настроек доступа и служебных архивов машин. Наборы и веса скачиваются у их авторов с зафиксированными ревизиями и проверками. Условия использования сторонних материалов определяются их авторами; публикация этого репозитория не меняет их лицензии.

Официальные источники: [TypeSafe](https://typesafe.ai/), [Laya](https://github.com/NandhaKishorM/laya), [BEIR](https://github.com/beir-cellar/beir), [BGE](https://huggingface.co/BAAI/bge-reranker-v2-m3), [Qwen3-Reranker](https://huggingface.co/Qwen/Qwen3-Reranker-8B).
