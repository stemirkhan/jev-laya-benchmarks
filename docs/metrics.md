# Дополнительные результаты

Значения из того же снимка данных, что и графики. Округлены только подписи.

NDCG@10 учитывает релевантность и положение документов в первой десятке. Значения от 0 до 1, больше - лучше. SciFact: 300 запросов, FiQA: 648, NFCorpus: 323. Внутри каждого варианта поиска реранкеры получают одинаковые 20 кандидатов.

С кандидатами BM25 и RRF направление изменений совпало: Laya снизила NDCG@10 на всех трех наборах, остальные модели повысили. Величины изменений различаются. Например, на FiQA потеря Laya составила 0,028 после BM25 и 0,085 после RRF.

## Пиковая видеопамять

| Модель | Allocated, GiB | Reserved, GiB |
|---|---:|---:|
| Laya Multilingual | 6,54 | 29,97 |
| BGE-reranker-v2-m3 | 1,37 | 2,03 |

Allocated - память тензоров через CUDA allocator; reserved включает кеш и не является минимальным требованием к VRAM. Пики основного теста на RTX 5090. Laya - FP32 с TF32, BGE - FP16, Qwen - BF16. Память Jev через API не измерялась.
